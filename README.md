# XeqM SN Factory - Mainnet Edition

A GUI tool built with Python and Tkinter to easily deploy, manage, and monitor XeqM Service Nodes using Docker.

## Features

* Multi-node deployment using Docker Compose.
* Auto-Watchdog for automated node restarts and public IP migration.
* Live synchronization status, blockchain height tracking, and network progress bar.
* Integrated wallet CLI tool utilities.
* Automated registration command generator for staking.

## Prerequisites

Before running the application, make sure you have the following installed on your system:

1. **Python 3.x**
2. **Docker Desktop** (Must be running in the background)
